# 037 手元からのデプロイは git を前提にせず、版の名前は既定で時刻にする

- 決めた日: 2026-11-24

## 背景

手元からのデプロイ（`make deploy`）は、プロジェクトの git のチェックアウトを指し、HEAD にちょうど 1 つ付いたタグを版の名前にしていた。コミットしていない変更があるときと、タグが無い・複数あるときは断っていた。

手元からのデプロイは、開発中に試しに出すときなどに使う。そのたびにコミットとタグを作るとは限らない。`release` ブランチとタグが要るのは、自動のデプロイ（ADR 029）だけでよい。

## 決定

- 手元からのデプロイは、指したディレクトリをそのまま使う。git のリポジトリでなくてよく、コミットしていない変更があっても断らない。
- 版の名前は、指定しなければ UTC の時刻（`YYYYMMDDTHHMMSSZ`）。`make deploy ... TAG=<名前>` で指定できる。使える文字は Docker のタグとして使えるもの。
- すでにある版の名前を指定したときは、上書きする。
- 自動のデプロイは変えない（ADR 029）。

## 理由

- 手元からのデプロイを、コミットやタグの手間なしに使えるようにする。
- 版の名前は、イメージのタグ・リリース一式の置き場所・今の版と前の版の記録に使うので、何かは要る。時刻なら重ならず、いつ出したかも分かる。
- 上書きを断る仕組みは足さない（シンプルさを優先する）。

## 採らなかった案

| 案 | 理由 |
|---|---|
| 今のまま、タグとコミットを要る | 開発中に試しに出すたびに、コミットとタグが要る |
| コミットの短いハッシュを版の名前にする | コミットしないで出すことがある |

## 引き換え

- 手元から出した版は、どのコミットかが記録に残らない（名前を `TAG=` で付ければ残せる）。
